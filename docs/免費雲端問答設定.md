# 免費雲端問答設定

網站保留在 GitHub Pages。Cloudflare Worker 執行雲端查詢，Supabase 驗證既有玩家帳號與審核狀態；Gemini 優先，Cloudflare Workers AI 備援。本機只負責整理資料與部署，不執行玩家的 AI 問答。

## 管理員需要準備

1. 建立 [Cloudflare 帳號](https://dash.cloudflare.com/sign-up)，維持 Workers Free；不要啟用 Workers Paid。
2. 在 [Google AI Studio](https://aistudio.google.com/apikey) 建立 Gemini 金鑰，使用未綁定付費方案的專案。不要把金鑰貼到聊天、前端設定或 GitHub。
3. 在 `cloud-ai` 目錄使用 Wrangler 登入 Cloudflare。金鑰用 `wrangler secret put GEMINI_API_KEY` 安全輸入；也支援目前帳號已設定的 `gemini_api` 秘密變數名稱。
4. 確認兩邊維持免費方案後，將 `wrangler.jsonc` 的 `FREE_ONLY_ACK` 改為 `true`，再部署 Worker。
5. 將部署得到的 HTTPS Worker 網址填入 `site-config.json` 的 `aiEndpoint`，例如 `https://aoi-free-guide.你的子網域.workers.dev`。重新發布網站。

帳號與金鑰尚未準備時，網站會顯示「雲端問答尚未啟用」，仍提供解包資料搜尋。可先啟用 Cloudflare，再加入 Gemini 金鑰；有金鑰後自動優先 Gemini。

## 額度與回答

- 每個已審核帳號每日最多 50 次，全站最多 400 次，以 UTC+8 午夜重設；這是網站上限，不保證供應商免費額度足以回答 400 次。
- 額度在 Durable Object 中計算，不依賴玩家瀏覽器。失敗或找不到依據不扣每日問題數，短時間重試仍受限制。
- Cloudflare 另設每日 8,500 Neurons 的保守預估上限。免費額度由同帳號其他服務共享，Cloudflare Free 平台限制是最後一道停止機制；不可升級付費方案。
- Gemini 429 暫停一分鐘，再嘗試備援；沒有可用免費服務時停止 AI，保留一般搜尋。
- AI 僅選擇送入模型的資料條目，伺服器驗證條目 ID 後顯示原始資料，模型生成的任意文字不直接顯示。每筆附模組檔案、SHA-256、資源路徑及 JSON 位置。
- 題目和檢索資料會送到供應商；不送玩家名稱、私人筆記、隊伍聊天或其他帳號資料。免費服務的資料處理仍以供應商條款為準。

## 解包與更新

在工作區執行 `work/extract_all_gameplay.py`，依目前安裝的每個 JAR 產生資源、檔案清單、完整 CFR 原始碼及逐模組查核清單。純效能與共用函式庫另列排除原因；不依「核心」檔名前綴判斷。未知與相容模組保留。反編譯失敗不能標示為完整。

再執行 `work/build_ai_knowledge.py` 建立 `data/ai` 問答索引。第一版檢索為配方、掉落、成就、標籤、世界生成與模組內建手冊；解包完成不等於所有程式邏輯已轉為可讀攻略。索引查核清單如實標示這個差異。伺服器上的設定、資料包覆寫尚需另行核實。

測試：`node --test cloud-ai/core.test.js`、網站 build、手機／電腦瀏覽器驗證。真正 Gemini 與 Workers AI 回答、帳號權限與平台免費方案，必須部署後再驗收。

參考：[Workers AI 免費額度](https://developers.cloudflare.com/workers-ai/platform/pricing/)、[SQLite Durable Objects 免費方案](https://developers.cloudflare.com/durable-objects/platform/pricing/)、[Gemini API 額度](https://ai.google.dev/gemini-api/docs/rate-limits)。

## 聊天與玩家隔離
