# 2026-10-06 網站更新

- 名稱改為「鐵血餘燼：王國飛翼／Ashes of Ironblood: Wings of the Realm」，縮寫 AOI。
- 收藏冊共用固定搜尋／篩選列、選單及展開／收合；圖鑑首頁加入跨冊想收集書。
- 修正裝備四個頁籤切換，網址與內容同步；排列方式按鈕不固定於滾動位置。
- 以原始模型修正 41 項 Java 模型側面 UV，並補全蠍子龍書頁插圖的截取範圍。害羞者移至首領清單末尾。
- 提高選中按鈕對比；手機逐項比較以頭像表頭縮短寬度，姓名由懸停／長按顯示。
- 網站管理員可將已核准玩家加入指定隊伍，不需要隊伍管理員批准；伺服器權限檢查限制此操作。
- 加入背景 Web Push：玩家按「開啟裝置通知」後要求裝置權限；訂閱與 VAPID 私鑰存於私有資料表。新需求／邀約由資料庫觸發寄送，取消的申請不向隊員推送。iOS 需加入主畫面且使用支援的系統版本。
- 懸賞留言板提供接單按鈕，申請與報酬物品支援名稱提示。
- 依目前 258 個 JAR 重新核對；新增按鍵搜尋、Ares HUD、機械動力魔法附加、XaeroPlus 教學，補上目前語音按鍵。移除一般性建議並改寫殖民地教學；步驟編號只顯示一次。
- 殖民地查詢含 54 種建築、208 個研究節點及 56 組職業對應。資料由 MineColonies 1.1.1282 註冊、工作模組、研究資源及判定程式抽取，區分建築總等級／單棟條件，顯示解鎖與後續分支。
- 90 項夥伴取得與材料內容同步至原攻略和網站搜尋；補上確切龍食機率、蛋掉落與食材來源。骷髏迅猛龍的蛋可用目前版本的生存配方製作。
- 依香蕉、黃蜂、黃黃翻譯包更新篩選名稱；翻譯包未提供的中文模組名沿用網站中文標籤。
