# 0.1.13 單一 JAR 與啟動前更新

玩家只需一個模組 JAR，不需要另外下載更新器 ZIP。首次載入 0.1.13，Windows／MultiMC 玩家會自動解出內建更新器、備份啟動器設定並設定啟動前指令。

請正常退出遊戲並完整關閉 MultiMC 一次，讓啟動器讀取新設定。往後每次開遊戲都先取得正式簽章版本清單；有新版時驗證、備份並替換，再於同一次啟動載入新版，不需再次重開遊戲。

0.1.8～0.1.12 玩家可由原機制自動取得 0.1.13：下載、關閉遊戲後套用，下一次載入 0.1.13 自動設定掛鉤。不是已執行遊戲的熱更新。

`/ai 版本`、`/ai version` 或 `/小助手 版本` 可查詢目前實際載入的版本和更新狀態；不需登入、不呼叫 AI、不消耗額度。已下载但未載入的新版不會被當成目前版本。`/ai 更新` 保留手動檢查，遊戲執行中下載的新版仍在退出後套用。

已有其他實例或全域啟動指令時，保留原設定，顯示提示並記錄在 `config/aoi_assistant/prelaunch/setup.log`，不自動串接。不支援的啟動器／系統沿用既有更新方式。`autoUpdate=false` 同時停用自動設定與啟動前更新。

更新器與固定脚本內嵌在已簽章發布的 JAR；不下載遠端腳本。使用同一 Ed25519 信任公鑰，驗證清單期限、SHA-256、大小、模組 ID 與版本，固定 HTTPS 來源、限制下載時間與大小、不允許降版。獨立 JVM 不鎖住 mods 裡的舊 JAR。

與原更新器共用更新鎖；實例仍執行時不替換模組。下載或驗證失敗保留舊版。安裝失敗嘗試回復；回復失敗停止並顯示備份位置。

首次安裝時，隱藏程序會等待目前 MultiMC 結束，再合併啟動前指令，防止舊設定快取覆寫；不會終止遊戲或啟動器，等待上限一天。本機內建更新器內容更動後，下一次載入新版模組會自動重新同步。

啟動器設定備份：`config/aoi_assistant/prelaunch/launcher-settings-*.cfg`。模組備份：`.minecraft/aoi-assistant-backups/`。關閉 MultiMC 後可恢復設定備份或移除 AOI 啟動前指令。

自動驗證與隔離整合測試不取代玩家實際 MultiMC→Forge 啟動驗收。
