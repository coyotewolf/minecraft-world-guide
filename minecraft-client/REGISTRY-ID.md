# 完整 ID 查詢（0.1.14）

查詢遊戲實際註冊的物品、方塊與實體 ID，包含模組命名空間，例如 `minecraft:chorus_fruit`。不要求實體已生成或出現在視野內。

- `/ai id 歌萊果`：按名稱查詢。
- `/ai id 實體 虛顎龍`：只查實體。
- `/ai id 方塊 石頭`：區分同名物品與方塊。
- `/ai id`：查指向的方塊或實體；沒有目標時查主手。
- `/ai id 手持`：只查主手物品。
- `/ai 識別碼 名稱`、`/ai ID 名稱` 亦可。

自然語言：`/ai 歌萊果的完整ID是什麼`、`/ai 我手上這把武器的ID是什麼`、`/ai 這隻虛顎龍的英文識別碼是什麼`。由 AI 判斷本輪查詢意圖、名稱及種類，交由遊戲讀註冊表，模型不直接編造 ID。指向／手持查詢使用提問當下的畫面快照，避免 AI 回覆前切換目標導致答錯。

指令只在本機執行、不需登入、不消耗 AI 額度。自然語言沿用既有帳號、模型、配額與聊天同步。查詢結果只同步到自己的聊天紀錄，不上傳整份遊戲註冊表。

支援顯示名稱、完整 ID 或名稱／ID 片段。優先精確比對；同名候選全部保留類型，最多列出 20 項並告知總數，過多時請縮小名稱或類型。查不到就回報找不到，不猜測 ID。完整註冊 ID 不包含 NBT 或某些模組自訂的附加識別資料。

舊客戶端不會收到不支援的 ID 工具操作。每次查詢是一次性工作，不定期掃描。
